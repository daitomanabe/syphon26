# Metal Fixtures

Phase 2 uses deterministic in-process Metal fixtures. These fixtures are generated by compute shaders during tests; this directory documents their expected shape.

## BGRA8 Color Bars

- Pixel format: `bgra8Unorm`
- Fixture name: `bgra8ColorBars`
- Pattern: four horizontal color bars across X: red, green, blue, white.
- Validation: GPU write pass creates the texture; GPU checksum pass samples the texture and writes a scalar checksum plus pixel count to small shared buffers.

## RGBA16F Gradient

- Pixel format: `rgba16Float`
- Fixture name: `rgba16FloatGradient`
- Pattern: exact half-float-friendly values based on `x & 3`, `y & 3`, and `(x + y) & 3`, with alpha fixed at 1.0.
- Validation: GPU write pass creates the texture; GPU checksum pass samples the texture and writes a scalar checksum plus pixel count to small shared buffers.

## Validation Rule

The tests do not read back the full texture. They only read the GPU-produced checksum and pixel count so the validation remains texture-oriented and does not become a transport design based on CPU frame readback.
